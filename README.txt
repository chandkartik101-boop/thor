Heroes Thor: GTA Powers (add-on, Forge 1.20.1) - UNTESTED SOURCE
Keys (rebind in Options > Controls > "Heroes Thor: GTA Powers"):
 Z Lightning Barrage - 6 bolts at the crosshair (up to 120 blocks)
 C Thunder Dash      - sonic-boom launch forward, damages nearby mobs
 K Ground Slam       - hop, dive, shockwave on landing (no fall damage)
 J Wind Blast        - telekinetic cone that throws mobs/players
 Y Thunder Charge    - toggle: Speed II, Resistance II, Strength II + auto-zaps nearby hostiles
Build: install JDK 17, then in this folder run:  gradlew build  (or "gradle build" with Gradle 8.x)
 You need the Forge 1.20.1 MDK wrapper (gradlew); copy gradlew + gradle/ from forge-1.20.1-47.2.0-mdk.zip.
Output: build/libs/heroesthor_gta-1.0.0.jar -> drop in mods/ next to heroesthor-0.8.0 jar.
Lightning sets fires/hurts you if you stand at the target; use on a server with trusted players only.
